# AccountFleet releases

Installers for [AccountFleet](https://github.com/pvbhanuteja/accountfleet) and the feed its in-app updater reads.

- Each release holds the macOS (Apple silicon and Intel), Windows and Linux (AppImage, deb, rpm) builds.
- `latest.json` in the newest release tells installed apps that an update exists. Every package is signed, and the app installs only packages that verify against the key built into it.

There is no source code here.
